# POMS Research Logic Skill

A Codex skill for building POMS-style research logic and academic writing frameworks for operations management, reliability engineering, maintenance optimization, CBM, Bayesian learning, and POMDP papers.

## Use Cases

- Improve paper introduction logic
- Frame research gaps and contributions
- Analyze POMS-style academic writing structures
- Turn method-driven drafts into phenomenon-driven research narratives
- Design literature review, model formulation, theory, and numerical experiment sections
